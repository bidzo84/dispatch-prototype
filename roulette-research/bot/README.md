# რულეტკის დამკვირვებელი ბოტი (v1)

**რას აკეთებს:** უყურებს ლაივ მაგიდას ეკრანზე, იწერს ყოველ სპინს დილერის სახელით, ამოწმებს ყველა ჩვენს ჰიპოთეზას და **ვირტუალურად** (ფულის გარეშე) ატარებს სტრატეგიას.
**რას არ აკეთებს:** რეალურ ფსონს არ დებს და კაზინოს საიტზე არ აჭერს.

## ინსტალაცია (Windows)
1. Python 3.11+ — https://www.python.org (მონიშნე „Add to PATH“).
2. Tesseract OCR — https://github.com/UB-Mannheim/tesseract/wiki (ინსტალერი). საჭიროა მხოლოდ ავტომატური რეჟიმისთვის.
3. ამ საქაღალდეში: `pip install -r requirements.txt`

## სრული რეჟიმი: „ჩართე და დატოვე“
ორ ფანჯარაში:
```
python observer.py --table "Crocobet #1"     # ჩაწერა + ბორბლის ვიდეო + ვირტუალური არენა
python board.py                              # ვირტუალური დაფა ბრაუზერში
```
- ყოველი სპინი იწერება: დილერი, სმენა, ნომერი, ბორბლის მიმართულება, **გაშვების უჯრა**, ბორბლის/ბურთის სიჩქარე.
- არენაში 4 სტრატეგია (თანაბარი, ოსკარი, კელი, პროგრესია) ეჯიბრება ერთმანეთს ერთსა და იმავე ნომრებზე.
- ყოველი ვირტუალური ფსონი იწერება `bets.csv`-ში — დრო, დილერი, ნომრები, ფსონი, შედეგი, მოგება/წაგება, ბალანსი — ისე, როგორც რეალური ანგარიშის ისტორიაში.
- თუ 3 წუთი ახალი სპინი არ ჩანს → ხმოვანი გაფრთხილება (მაგიდიდან გამოგდება / სტრიმის გაჩერება).

## ბორბლის ვიდეო (wheel.py)
1. `calibrate.py`-ში მონიშნე „wheel“ — მართკუთხედი ზუსტად ბორბლის კიდეებზე.
2. `python wheel.py preview` → `wheel_preview.png`: მწვანე რგოლები უჯრებზე უნდა იყოს, ცისფერი — ბურთის ბილიკზე.
3. თუ არ ემთხვევა, `config.json`-ში დაამატე/შეცვალე:
   `"wheel_geom": {"pocket_r": [0.55, 0.75], "ball_r": [0.80, 0.95], "center": [0.5, 0.5], "mirror": false}`
4. `python wheel.py` — თვითტესტი სინთეტიკურ ბორბალზე.

სიზუსტე სინთეტიკურ ტესტზე: მიმართულება 40/40, გაშვების უჯრა ზუსტად 35/40, ±1 უჯრით 40/40.
რეალურ სტრიმზე დამოკიდებულია კამერის კუთხეზე, ხარისხზე და კადრების სიხშირეზე.

## ინსტალაცია (Mac)
1. Python 3.11+ — https://www.python.org/downloads/macos/ (ოფიციალური ინსტალერი; მასში tkinter უკვე არის).
2. Tesseract (ავტომატური რეჟიმისთვის): Homebrew-ით — `brew install tesseract` (Homebrew: https://brew.sh).
3. Terminal → ამ საქაღალდეში: `python3 -m pip install -r requirements.txt`
4. **ეკრანის ჩაწერის ნებართვა:** System Settings → Privacy & Security → Screen & System Audio Recording → ჩართე **Terminal** → Terminal გადატვირთე. ამის გარეშე ბოტი მხოლოდ შავ ეკრანს დაინახავს.
5. Mac-ზე ბრძანებებში `python`-ის ნაცვლად წერე `python3`.

## ნაბიჯები
| # | ბრძანება | რას აკეთებს |
|---|---|---|
| 1 | `python calibrate.py` | ეკრანზე მონიშნავ: ისტორიის ზოლს, ბოლო ნომერს, დილერის სახელს |
| 2 | `python observer.py --table "მაგიდის სახელი"` | ავტომატური ჩაწერა → `spins.csv` |
| 2ბ | `python observer.py --manual` | ხელით ჩაწერა (თუ OCR არ მუშაობს) |
| 3 | `python analyze.py` | ყველა ტესტი: ბორბლის ბიასი, დილერის ხელწერა, დილერის ამოცნობა, ფაქტები 8ბ/9/10 |
| 4 | `python strategy.py paper --k 12 --staking kelly` | სტრატეგია ჩაწერილ მონაცემებზე (ვირტუალურად) |
| 4ბ | `python observer.py --paper ...` | ვირტუალური ფსონები ლაივში |

## ფსონის ზომის სისტემები (`--staking`)
| სისტემა | აღწერა | როდის |
|---|---|---|
| `kelly` (**რეკომენდებული**) | ფსონი = ბიუჯეტის წილი × დამტკიცებული უპირატესობა (¼ Kelly). უპირატესობა არ არის → ფსონი 0. გაორმაგება არ არის | ძირითადი რეჟიმი |
| `flat` | ყოველთვის ერთი და იგივე ფსონი | კვლევის ფაზა — სუფთა შედეგი |
| `oscar` | Oscar's Grind: ფსონი იზრდება მხოლოდ მოგების შემდეგ | თუ პროგრესია გინდა, რბილი ვარიანტი |
| `dalembert` | წაგებაზე +1, მოგებაზე −1 | ❌ 12–18 ნომერზე არ ერგება (წაგება უფრო ხშირია → ფსონი იზრდება) |
| `prog` | ფიქსირებული პროგრესია `--prog 1,2,3,3,6,7` | შედარებისთვის |

`python strategy.py compare --k 12 --q 0.38` — ყველა სისტემის შედარება (q = მოხვედრის ალბათობა).

## სტრატეგიის ხელსაწყოები
- `python strategy.py table --k 12 --prog 1,2,3,3,6,7` — თითო საფეხურის მოგება/ზარალი
- `python strategy.py suggest --k 15 --levels 6` — სწორი პროგრესია k ნომრისთვის
- `python strategy.py mc --k 12 --bankroll 100 --stop-loss 60 --take-profit 20` — 20 000 სესიის სიმულაცია

## ნომრების არჩევა
ბოტი ფსონს **მხოლოდ** მაშინ ურჩევს, როცა დილერს წინა სმენებიდან ≥300 სპინი აქვს და ხელწერა სტატისტიკურად ძლიერია (z ≥ 4). სამართლიან დილერზე ის ჩუმადაა — ეს სწორი ქცევაა.
